# Lista de Exercícios 2 — Repetição e Vetores em C

Repositório criado para armazenar os exercícios da segunda lista da disciplina de **Algoritmos e Pensamento Computacional**, desenvolvidos em linguagem **C**.

Nesta etapa, os exercícios avançam para conceitos de **vetores, repetição, busca, contagem e análise de dados**, exigindo uma aplicação maior de lógica para manipulação de conjuntos de valores.

## Conteúdos praticados

Os exercícios trabalham principalmente:

- Vetores
- Índices e posições
- Estruturas de repetição
- Armazenamento de múltiplos valores
- Percorrimento de vetores
- Soma e média de elementos
- Contagem de elementos
- Identificação de maior e menor valor
- Números pares e ímpares
- Ordem inversa
- Busca de valores
- Identificação da posição de um elemento
- Contagem de ocorrências
- Criação de um segundo vetor
- Verificação de ordem crescente
- Processamento de quantidade variável de dados

## Exercícios

A lista é composta por **15 exercícios**, começando com operações básicas sobre conjuntos de números e evoluindo para problemas que combinam vetores, repetição e diferentes formas de análise dos dados.

Entre os problemas resolvidos estão:

- Leitura e apresentação de valores na ordem digitada;
- Soma e média de elementos;
- Contagem de números pares e ímpares;
- Identificação do maior e do menor valor;
- Apresentação dos valores em ordem inversa;
- Busca de um valor dentro de um vetor;
- Identificação da posição de um elemento;
- Contagem de quantas vezes determinado valor aparece;
- Criação de um vetor contendo o dobro dos valores de outro vetor;
- Verificação se os elementos de um vetor estão em ordem crescente;
- Identificação da posição do maior e do menor elemento.

O último exercício combina várias dessas operações, trabalhando com uma quantidade variável de números até que o usuário informe `0`. Ao final, são calculados quantidade de elementos, soma, média, maior valor, menor valor, quantidade de pares, quantidade de ímpares e a presença de um determinado valor no vetor.
